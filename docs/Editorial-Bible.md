# Editorial Bible

Write with clarity. Separate objective facts from editorial analysis. Attribute evidence and label
uncertainty, interpretation, rumor, and opinion.

Canonical world and publication rules now live in the [World Guide](WORLD_GUIDE.md) and
[Underground Press guide](UNDERGROUND_PRESS.md). Project-wide writing conventions live in the root
[Style Guide](../STYLE_GUIDE.md). This file remains as a short editorial entry point rather than a
competing rulebook.
