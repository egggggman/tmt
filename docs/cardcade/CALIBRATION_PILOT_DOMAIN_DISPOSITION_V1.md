# Calibration Pilot Domain Disposition V1

Status: review candidate; no calibration games executed and no Pilot behavior changed.

## Decision ownership

| Decision surface | Owner | Supplied observation / filtering |
|---|---|---|
| Main action, attack, blocks, Sneak | Pilot | Typed GameViewV2 plus only legal ActionOptions generated by the engine; illegal options are never supplied. |
| Priority / responses | Pilot | PriorityViewV2 exposes the acting seat, stack summary, legal options, and public context; engine owns turn/priority scheduling and pass resolution. |
| Scry | Pilot | ScryView with inspected top cards and legal ScryOptions; only represented inspected information is exposed. |
| Hand-bottom draw, discard/draw | Pilot | Typed choice views/options; engine owns movement legality and resolution. |
| Paramecia exile/return, Raphael exile/play, counter targets, Mutagen targets | Pilot chooser callback | Offered candidates are authoritative, zone- and controller-filtered; target invalidation revalidates and fails closed. |
| Alliance keyword choice, stun target, food search, jury-rig | Deterministic engine chooser | Default chooser selects the first listed legal option; no hidden information is consulted. |
| Legend rule | Deterministic engine chooser | Listed same-name permanents only; one legal permanent is selected deterministically. |
| Mana color (Frog Butler) | Pilot choice where required | Color is an explicit offered choice and is recorded in the floating ledger; payment revalidates and consumes exact produced mana. |
| Combat step transitions, state-based actions, cleanup, end-turn expiry | Deterministic engine rule | Engine owns scheduling and lifecycle transitions; no Pilot discretion. |

No unknown or unowned chooser is permitted in the calibration runner. An unrecognized decision, malformed option, missing typed view, invalid target, or incomplete evidence fails closed and stops the run.

## Observation boundary

The frozen Pilot receives typed public GameViewV2 / PriorityViewV2 / ScryView values and immutable legal option tuples. Own-hand data is exposed only to its owner; opponent hand and hidden library identities are excluded. Scry inspection exposes only the explicitly inspected top cards. Stack, battlefield, zone, counters, mana, and event-derived fields are limited to the declared public/context contract. Runtime object IDs are treated as opaque identifiers and are not strategic card identity beyond fields intentionally present in the typed view.

Filtering is engine-authoritative: options are generated from current legal state, then passed unchanged to the Pilot. Pilots must return one supplied option; acceptance of an option outside the tuple is an error. Newly closed Menace, Leonardo, Paramecia, Raphael, Ooze Spill, Tunnel Rats, Frog Butler mana/Reach, and Michelangelo replacement semantics participate through the same authoritative option and lifecycle paths.

This disposition establishes ownership and permitted observation for the exact frozen ten-deck full-gameplay protocol. Pilot Fitness remains a bounded demonstrated-surface PASS. Privacy and filtering are dispositioned here by contract and fail-closed enforcement; this document does not authorize execution or claim strategic competence beyond that surface.
