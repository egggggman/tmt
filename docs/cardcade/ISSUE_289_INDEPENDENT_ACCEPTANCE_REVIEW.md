## Defensible threshold before seeking control authorization

1. **Zero unresolved P0/P1 mechanics on the frozen ten-deck roster.** Implement faithful general semantics, or independently prove a specific clause unreachable with authenticated pilot/schedule state. Historical zero use does not waive it. Correct all four partial cases. A minor exception requires a bounded legal-opportunity and sensitivity argument accepted separately; none is established here.
2. **Rule and decision fidelity.** For each relevant family, demonstrate legal payment, timing, targets, stack ordering, layers, state-based actions, zones, deterministic replay, and a pilot path that can choose a meaningful action. Reconcile covered scanner positives with executable tests. There must be no unclassified clause.
3. **Freeze one tested runtime.** Pass focused invariants, full regression/CI, structural deck/catalog/schedule authentication, and deterministic replays. Any further semantic or pilot change gets a new content identity; neither #290 nor #291 identity is compatible with Combined 007.
4. **Only after this gate**, request separate authorization for the unchanged balanced-start 45-cell, 4,500-game Baseline 005 control and replay. Preserve Combined 007 as historical. Design Studio owns later balance interpretation and deck changes.

**Status:** Baseline 005 preserved. The engine semantic closure gate remains the critical path.
