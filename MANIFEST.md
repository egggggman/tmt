# TMNT Design Studio Manifest

## Mission
Document, analyze, preserve, and explore the design philosophy behind the TMNT Magic: The Gathering products.

## Core Principles
1. GitHub is the canonical source.
2. Preserve everything important.
3. Separate source data from editorial analysis.
4. One source of truth.
5. Everything has a home.
6. Record architectural decisions.
7. Quality over quantity.
8. Build for the long term.
