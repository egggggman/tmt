## Enduring foundation

- GitHub is the canonical project source.
- Preserve important knowledge, Evidence, decisions, and history.
- Separate Magic Facts, intent, analysis, recommendation, and presentation.
- Store facts. Compute intelligence. Preserve decisions.
- Every influential result must be explainable.
- Prove Standard before considering other Magic formats.
- Automate derivation; curate judgment; document Overrides.
- Balance Character identity with coherent, strong Standard deck design.
- Evolve through immutable Deck Versions and playtest Evidence.
- Build one trustworthy reference path before expanding broadly.
