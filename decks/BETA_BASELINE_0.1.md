## Real-game beta protocol

There are 45 unique pairings. Use two passes:

### Pass A — broad calibration

Play each pairing twice, swapping the starting player: **90 games**. Do not edit any deck during
this pass. Capture winner, starting player, mulligans, ending turn, plan execution, pilot fun,
opponent fun, character feel, and one concrete friction point.

### Pass B — targeted confidence

Select only pairings with repeated non-games, strong imbalance, low fun, weak character identity,
or suspicious rehearsal discrepancies. Play four additional games per selected pairing, alternating
the starting player.

Balance from repeated real-game observations, not heuristic percentages. Make the smallest change
that addresses the observed problem and preserve it as Prototype 0.2.
