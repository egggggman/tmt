# Roadmap

## v0.1.0 — Architecture and Database Foundation

- Consolidate and verify repository documentation.
- Freeze canonical terminology.
- Record accepted architectural decisions.
- Define SewerGraph domains and migration plan.
- Add Python project scaffold.
- Implement and validate `tmnt init`.

## v0.2.0 — Magic Facts and Capability Engine

- Implement Scryfall bulk-data importer.
- Import Oracle-level card data and printing data safely.
- Track Standard legality.
- Seed the canonical Capability taxonomy.
- Implement explainable Capability rules.
- Add documented Capability overrides.
- Verify repeatable imports and recomputation.

## v0.3.0 — TMNT Knowledge and Leonardo

- Seed Characters and Themes.
- Create Leonardo's first Design Intent.
- Map Themes to Capabilities.
- Add experience goals, strengths, and accepted weaknesses.
- Generate the first Character Dossier.

## v0.4.0 — Context-Aware Deck Design

- Implement Deck Profile analysis.
- Add mana-curve, capability, theme, and synergy diagnostics.
- Implement context-aware candidate ranking.
- Generate explainable add/cut recommendations.
- Assemble Leonardo's first complete Standard-legal Sewer Deck.

## v0.5.0 — Playtesting and Refinement

- Record Deck Versions and playtest sessions.
- Separate observations from opinions.
- Refine capability rules and overrides from evidence.
- Produce Deck and Card Dossiers.
- Complete the Leonardo reference milestone.

## v1.0.0 — First Stable Studio Release

- Stable database migrations and importer.
- Explainable recommendations.
- Complete Leonardo reference implementation.
- Tested CLI workflows.
- Contributor documentation.
- Release backup and tagged GitHub version.

## Later work
