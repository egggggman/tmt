# Style Guide

- Markdown first.
- Use consistent, descriptive headings.
- Separate Magic Facts, computed analysis, interpretation, opinion, and presentation.
- Use terms and capitalization from the [canonical Glossary](docs/GLOSSARY.md).
- Label future concepts as planned until implementation and release history verify them.
- Cross-link canonical documents instead of copying definitions.
- Preserve historical context and clearly label subsystem-specific vocabulary.
- Prefer plain, timeless language over hype or clickbait.
- Follow the [Underground Press guide](docs/UNDERGROUND_PRESS.md) for in-universe publication.
